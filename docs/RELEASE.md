# v1.0.0 Release Verification

This repository contains the v1.0.0 release candidate produced in the local build workspace and published here as the standalone GitHub project.

The local verification recorded 75 Python tests passed, 1 skipped and 81.10% coverage. Ruff, mypy, Bandit, pip-audit and frontend dependency/build checks were explicitly not run where their executables or registries were unavailable.

The repository does not claim a passing result for checks that were not executed.
