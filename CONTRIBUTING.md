# Contributing

Contributions should represent genuine engineering work.

## Expectations

- add or update tests with behavioural changes
- keep changes focused
- run linting, type checks, and tests before submission
- document architectural decisions when appropriate
- never add private or sensitive datasets
- never manufacture history, contributors, bugs, or task evidence

Small focused changes are preferred when they represent real independent engineering work. Do not split work artificially merely to increase commit count.
